


# Provenance: LLM_Synthetic_Preferences

## Identifier

`LLM-Synthetic-Preferences`

## Collector

Center for Humanities Computing, Aarhus University (AU)

## Legal Basis

Legal basis for research under Danish data protection regulation (forskningshjemmel)

## Sharing

Joint data controller agreement in project; public sharing of fully synthetic outputs under CC-BY 4.0

## Collection Date

Synthetic data generated iteratively from March 2025 to December 2026

## Origin

Derived from prompts based on publicly available deliberation transcripts, civic data, and domain-informed templates. All outputs generated by Llama 3.3 70B instruct-tuned model.

## Software and Infrastructure

- LLM framework: Llama 3.3 instruct (70B)
- Prompt engineering and generation orchestrated in Python using Hugging Face `transformers` and `accelerate`
- Execution on AU ERDA + DeiC Interactive HPC

## Reproducibility

- Prompt seeds, sampling parameters, and generation scripts versioned in Git (available in project repository)
- Each generation batch logged and archived with metadata (see event log)

## Notes

The dataset contains no real personal data and has undergone content inspection and filtering for sensitive or identifiable artifacts.
